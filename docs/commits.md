## 下次提交怎么写

**Summary**（一行，必备版本号）

```
v2026.10.08 一句话说清这批最重要的改动
```

**Description**（按"改了什么 / 为什么"分块，用 `·` 起头，别超过一屏）

```
模块名：一句话概括
· 具体改动
· 具体改动

修复
· 症状 → 根因 → 怎么修的

工程
· 测试 N → M 项
· README / CHANGELOG 更新
```

写完之后：

1. 把两段一起贴进 GitHub Desktop
2. 同时把内容整理进 `../CHANGELOG.md`，并在本文件追加一节
3. 同一天再发一批就递增补丁号（`.1` → `.2`），并在上面的表里加一行
