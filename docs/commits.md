## v2026.10.06.2

> 第三批：一次完整体检发现"敌人血量是指数、玩家伤害是加法"，
> 后期必然打不动。这批围绕它修，外加体验与工程补齐。

### Summary

```
v2026.10.06.2 击破奖励 + 超时过载修后期难度，新增图鉴与跨局存档
```

### Description

```
后期难度曲线（核心）
· 体检发现：第 10 关 Boss 要打 99 秒、第 20 关 137 秒，12 分钟只能推到第 20 关
· 根因：敌机血量 ×1.2^关卡 再叠每十关 ×2.2 台阶（乘法），
  而玩家强化是加法且很快点满 —— 两条曲线必然发散
· 新增「击破奖励」：每击破一位 Boss，伤害 ×2（永久、可叠加）
  这是一条独立的关卡进度乘区，同时作用于子弹与持续伤害
· 修复后：第 10 关 Boss 53 秒、第 20 关 43 秒，12 分钟能推到第 27 关
· 新增「超时过载」兜底：Boss 战打满 10 分钟后每秒掉 2% 最大生命
  → 任何构筑都不会出现打不完的僵局

图鉴 / 玩法（新文件 js/codex.js）
· 主菜单新增入口，三个标签页：玩法 / 增益（113 个）/ Boss（6 位）
· 数据从 POOL 与 ROSTER 现读，以后加内容自动同步

跨局存档
· 原来只存最高分，现在额外存最高关卡 / 累计击杀 / 击破 Boss / 局数
· 主菜单与结算界面都会显示；损坏的存档安全降级

修复
· 面板在小窗口会盖住玩家 → 自适应：先压扁行高、再按重要度截断并提示
· 生命值显示 '♥'.repeat(1e9) 会 RangeError → 封顶并改用 ♥×N
· 13 行模块启动日志刷控制台 → 收进 Game.log，默认静默（?debug 打开）
· CI 注释写死的"313 项" → 改成不写死

舰队流
· 僚机开始吃「命中积累」，但只有本体的 25%（和数值继承同比例）

打包（tools/build.js）
· 新增源码 zip 生成（内置极简 ZIP 写入，零依赖）
  之前那个 zip 是手工打的、缺了全部新内容且没有生成脚本
· 单文件版自动去注释（保留换行，报错行号不变）：240.9 → 213.2 KB
· 新增构建自检：不允许混进 dist/ .git/、关键文件必须在

工程
· 冒烟测试 456 → 498 项
· 测试台 DOM 桩补上 querySelectorAll / dataset，新增 fireWindow()
```

### 踩坑记录

> 去注释功能第一版把"行首是 `*` 的行"当成 JSDoc 续行删掉，
> 结果把 `S.dotPerStack = base * (1 + 0.25 * ...)` 这种**乘法换行续写**也删了，

## 下次提交怎么写

**Summary**（一行，必备版本号）

```
v2026.10.08 一句话说清这批最重要的改动
```

**Description**（按"改了什么 / 为什么"分块，用 `·` 起头，别超过一屏）

```
模块名：一句话概括
· 具体改动
· 具体改动

修复
· 症状 → 根因 → 怎么修的

工程
· 测试 N → M 项
· README / CHANGELOG 更新
```

写完之后：

1. 把两段一起贴进 GitHub Desktop
2. 同时把内容整理进 `../CHANGELOG.md`，并在本文件追加一节
3. 同一天再发一批就递增补丁号（`.1` → `.2`），并在上面的表里加一行
