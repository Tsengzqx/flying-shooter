# 星际突袭 · STAR STRIKE

**自动开火，专心走位。在一轮轮强化中打造你的战机，挑战越来越强的 Boss。**

《星际突袭》是一款竖版飞行射击小游戏。击毁敌机获得经验，升级时从三张强化卡中选择一张：用弹幕铺满战场、带着僚机编队出击，或让持续伤害慢慢侵蚀后期 Boss。

当前下载版已使用全套高科技舰船外观，并加入深空与 Boss 专属星球；仲裁者双环、噬星者吞噬口会独立转动。美术升级不改变原有碰撞和战斗规则。

## 🎮 开始游戏

### 在线玩

**[点击开始 →](https://elaborate-mandazi-62d152.netlify.app/)**

电脑和手机都能用浏览器打开。手机上按住战斗区域拖动，就能控制飞机。

### 下载后离线玩

- **只想玩游戏**：保存 [单文件版「星际突袭.html」](dist/星际突袭.html)，用浏览器打开即可。
- **下载了整个项目**：直接打开 `index.html`。
- **拿到的是压缩包**：先完整解压，再打开里面的 `index.html`。不要只把它单独拖出来。

不需要安装游戏客户端。单文件版下载好后，无需联网也能玩；手机建议优先使用在线版。

> 在线版以网站已发布的内容为准。下载版和在线版的更新进度可能不同。

## 第一局怎么玩

1. **先活下来。** 不用一直按射击键，把注意力放在敌弹和侧面的躲避空间上。
2. **击毁敌机攒经验。** 屏幕底部是经验条，满了就会升级并弹出强化选择。
3. **选一条主路线。** 先让几张能互相配合的卡成形，再补生命、护盾或清弹能力。
4. **每 10 关迎战一位 Boss。** 击破后获得大量经验、补给和本局持续生效的伤害奖励。
5. **挑战更远的关卡。** 第 60 关之后，Boss 会以更强的形态再次登场。

**强化来自升级，不是单纯过关。** 卡片选取期间战斗会暂停，可以慢慢比较。

## 选一套喜欢的打法

流派可以混搭，不必从开局就锁死路线。下面这些卡名都能在图鉴里找到。

| 流派 | 适合怎样的你 | 可以留意的强化 |
|---|---|---|
| 🐝 **弹幕流** | 想尽快提升火力，前中期清怪更舒服 | 蜂群弹幕、弹幕洪流、前向弹道 |
| 🎁 **道具流** | 喜欢收集补给，让每次拾取都带来成长 | 补给协议、磁力吸附、装备强化 |
| 📘 **升级流** | 想靠经验和等级逐渐滚起优势 | 经验增幅、成长之力、熟练加速 |
| 🛸 **舰队流** | 喜欢带着僚机作战，让编队帮你输出 | 僚机、火力共享、快速循环 |
| ☢️ **持续伤害流（辐射流）** | 愿意花时间成形，专门对付后期高血量 Boss | 辐射源、衰变强化、临界质量 |

新手可以先从**弹幕流配少量生存强化**开始。生命强化、复合装甲、紧急回避、点防系统等通用增益，也能补进任何流派。

### 想玩后期持续伤害，怎么选？

这套打法的重点不是一发打多少，而是**持续挂毒、把层数叠起来**。

- **先拿「辐射源」**：它是持续伤害的起点，单拿燃烧弹或剧毒弹还不能点燃这条路线。
- **补叠层和伤害**：衰变增幅、燃烧弹帮助叠层；衰变强化、高频衰变让持续输出更强。
- **补上限和续航**：临界质量提高层数上限，半衰期延长、剧毒弹让你走位时不容易断毒。
- **层数越高，后劲越足**：超过 30 层后，持续伤害和临界引爆还会获得额外提升。

**辐射源达到 3 级，且累计获得 12 层辐射流增益后，会解锁「Boss 侵蚀」。** 它专门针对第 10 关之后的 Boss，越到后期越能发挥作用。

对 Boss 维持至少 **40 层**持续伤害，侵蚀会在 **8 秒**内逐渐增强；叠到 **100 层**时达到完整的层数收益。满配时，除了原有持续伤害，还能每秒侵蚀约 **2.4% 的 Boss 最大生命**。

> 记得边躲边补伤害：层数掉得太低或毒到期，就要重新积累。持续伤害有自己的强化路线，单纯堆子弹伤害和子弹暴击，不能替代辐射流的专精。

## 强化卡怎么选

- **蓝 → 青 → 紫 → 金**：品质越高，越容易见到能改变打法的效果，但也要看它是否适合当前构筑。
- **同一张卡可以继续升级**：留意卡面上的当前等级和「升级后多获得什么」。满级后不会再抽到。
- **金色不是开局就能拿**：某个流派累计获得 8 层增益后，该流派的金色卡才有机会出现，并不是达到门槛就必出。
- **越专精，越容易继续成形**：已经投入较多的流派，后续更容易遇到相关卡；仍然可以中途混搭或转型。

拿不准时，优先考虑「现在能帮我活下来或更快清怪的卡」，不用为了等某张金色卡一直硬撑。

## 补给别认错

击毁敌机后，有时会掉下这些道具：

| 标记 | 捡到后的效果 |
|---|---|
| **S** | 三向散射，临时增加火力覆盖 |
| **R** | 高速连发，临时提高射速 |
| **D** | 能量护盾，抵挡一次伤害 |
| **＋** | 维修包，回复 1 点生命 |

补给要靠近才能捡到。不要为了追一个道具，把自己挤进弹幕死角；磁力吸附可以让拾取轻松一些。

## Boss 来了，注意什么

Boss 登场时，远处会缓缓浮现一颗与它配色呼应的星球：金色荒岩、紫色气态星、熔岩星、青色冰海星、暗紫霜岩星，以及带星环的巨行星。它们大小不同，击破 Boss 后会渐渐隐去。

**星球只是远景，不会挡子弹，也没有碰撞伤害。** 普通关卡则能看到暗星云、银河尘埃与缓慢移动的远近星点。

| 首次出现 | Boss | 应对时留意 |
|---|---|---|
| 第 10 关 | **钢铁蜂巢** | 留意它召来的小怪，别只盯着 Boss |
| 第 20 关 | **虚空掠夺者** | 齐射后会瞬移，及时调整位置 |
| 第 30 关 | **熔核巨舰** | 弹墙会留下缺口，先找路再输出 |
| 第 40 关 | **深空仲裁者** | 注意旋转弹幕，别被逼到边缘 |
| 第 50 关 | **终焉之影** | 后段会周期性隐身，不要因此忽略场上的弹幕 |
| 第 60 关 | **噬星者** | 弹幕组合更多，给自己留足躲避空间 |

Boss 血量降低后会切换阶段，攻击也会变得更凶。**看缺口、留退路，比贪几次命中更重要。**

普通关里也有需要留意的敌人：黄色冲角机会先停下蓄力再俯冲；分裂体被击毁后还会分出小飞机；带金色光环和星标的精英怪更难对付，但奖励也更丰厚。

## 常见问题

### 最高分会保存吗？能接着上一局玩吗？

最高分、最高关卡等战绩会保存在当前浏览器中，**不是进行中对局的续玩存档**。刷新或关闭页面会结束当前这一局。

更换浏览器、设备或清除网站数据后，记录可能不同或消失；隐私模式下也可能无法保留。

### 为什么后期子弹变细、特效变暗了？

这是自动开启的低光效果，用来减轻密集弹幕带来的刺眼感。**伤害、射速和命中判定不会因此变弱**，敌弹仍保持醒目，方便躲避。

### 为什么没有声音？

先点击「开始游戏」，让浏览器允许播放声音。电脑端可按 `M` 检查是否静音，也可以确认浏览器标签页和设备音量。

### 怎么发给朋友玩？

手机用户直接分享[游戏网址](https://elaborate-mandazi-62d152.netlify.app/)最方便。电脑用户也可以发送下载好的 **「星际突袭.html」**，对方用浏览器打开即可。

如果聊天软件只显示文件预览，先保存文件，再选择浏览器打开。
