## 核心循环

```
自动开火 → 击毁敌机 → 获得经验 → 经验条满 → 等级 +1 → 【三选一强化】 → 变更强 → 打更难的关
```

**强化不靠过关，靠升级。** 越主动清怪、越能滚起雪球。
屏幕底部是经验条（左侧等级，右侧 `当前经验 / 升级所需`）。

## 增益系统（113 个）

### 四档品质

| 品质     | 颜色    | 说明                    |
| ------ | ----- | --------------------- |
| 普通     | 蓝     | 基础强化                  |
| 稀有     | 青     | 有明确取舍或机制              |
| 史诗     | 紫     | 强力机制，每个流派都有 4~6 个     |
| **金色** | **金** | **流派的终极增益，需要解锁，概率极低** |

### 金色增益的解锁规则

- 某个流派累计获得 **8 层增益** 后，该流派的金色增益才会进入抽取池
- 基础权重只有 **0.8**（普通是 62），所以出现概率**极低**
- 权重随**玩家等级**提升：`0.8 × (1 + 等级 × 0.12)`，等级越高越容易见到
- 金色增益只有 1 级，拿到就是质变
- 通用流派没有金色增益（金色只属于五大流派）

### 满级增益的出现概率为 0

任何增益拿到最高级（例如「弹跳弹」2 层）后，**会被彻底移出抽取池**，出现概率严格为 0
（过滤 + 权重双重保险，有 3000 次抽取的测试守着）。全部增益都满级时，升级不会再弹出强化面板。

### 流派倾向（越玩越专精）

系统会统计你在每个流派上投入的层数，然后调整出现概率：

| 情况       | 权重              |
| -------- | --------------- |
| 主导流派     | 最高约 **×2.1**    |
| 冷门流派     | 最低约 **×0.5**    |
| **通用增益** | **恒为 ×1（不受影响）** |

也就是「你玩什么流派，就更容易抽到什么流派的增益」，同时保留转型的可能。

### 卡面会告诉你「升级多拿到什么」

每张强化卡都写了两行：**当前效果** + **升级 +1 级额外获得什么**，例如：

```
〰️ 波动弹                       [通用]
子弹左右摆动前进，横向覆盖更宽
升级 +1 级：摆动幅度 +60%，波频更高
Lv 1 → 2
```

### 🛸 舰队流（15 个）— 指挥一支僚机编队

你不再是一架孤机。舰队流的核心是**僚机数量**，上限 **20 架**。

**最关键的一条规则：僚机继承本体 25% 的数值加成。**

不是简单的"固定伤害"，而是**逐项继承** —— 本体的弹道数量、射速、弹速、体积、穿透、追踪、**命中积累**……僚机都吃四分之一。
所以你在别的流派堆的东西，僚机同样受益。而这个继承比例**本身也能升级**（数据同步），最高可以拉到 100%（和本体同数值）。

```
本体伤害 10 → 僚机伤害 = 1 + (10 − 1) × 25% = 3.25
本体额外 12 条弹道 → 僚机多 3 条（四舍五入，不是直接抹掉）
本体命中积累 +40.0 → 僚机 +10.0
```

> 弹道与穿透用**四舍五入**而不是向下取整：25% 继承下 `floor` 会让 3 条额外弹道白白归零，
> 玩家会以为「僚机根本没继承本体」。四舍五入让继承看得见，曲线也更平滑。

> **命中积累也按 25% 继承**：僚机子弹会带上属于自己的那份加伤（本体的 1/4），
> 而不是白板。它走的是每颗子弹自带的 `bonus` 字段，和本体那条互不干扰。

> **追踪转向率是唯一的例外**：僚机只继承 **60%**（而不是 25%）——
> 因为 25% 会让 20 架 × 5 发全部带追踪，屏幕会被"自动瞄准"统治。

### ☢️ 辐射流（18 个）— 一条**独立于子弹**的持续伤害通道

**辐射 / 剧毒 / 燃烧 三种伤害在数值上是同一种伤害。** 它们共用同一份层数、
同一条结算管线（`applyDot()` → `tickDot()`）和同一套公式，只是"投毒方式"不同：
燃烧叠得猛、剧毒拖得久、辐射是引擎本身。

**核心机制：层数同时提升"每跳伤害"和"跳数频率"**

```
每层每秒伤害 = 0.32 × 辐射源层数
             × (1 + 0.25×衰变强化) × (1 + 0.20×燃烧弹) × (1 + 0.18×剧毒弹)
层数上限     = 15 + 6×辐射源 + 10×临界质量 + 4×燃烧弹        （熔毁协议 ×2）
每跳伤害     = 当前层数 × 每层每秒伤害 × 0.5（固定参考间隔）
跳数间隔     = 0.5s × 0.88^高频衰变 ÷ (1 + 0.008 × 层数 × 衰变链)   （下限 0.05s）
实际 DPS     = 层数 × 每层每秒伤害 × (0.5 ÷ 跳数间隔)
```

也就是说层数不是线性收益：**叠到 20 层的伤害远不止 20 层的 2 倍**，
而"跳数间隔"是**独立的第二个乘区** —— 间隔减半，DPS 直接翻倍。

> **一个踩过的坑**：早期版本把跳伤写成 `层数 × 每层DPS × 实际间隔`，
> 于是 `DPS = 跳伤 ÷ 间隔 = 层数 × 每层DPS`，**间隔被完全约掉** ——
> "高频衰变"和"衰变链"两个增益一点用都没有。
> 现在跳伤用**固定参考间隔 0.5s** 计算，间隔才真正变成乘区。
> 冒烟测试里有一条专门的回归断言守着它。

#### ⚠️ 这条通道不吃任何常规子弹加成

这是本流派最重要的规则 —— DOT 是**第二条并列的伤害通道**，不读子弹的任何属性：

| 常规子弹属性 | 对 DOT 的影响 |
|------|------|
| 子弹伤害（火力强化 / 聚能弹 / 重型弹头 / 装备强化 / 成长之力 …） | **无效** |
| 子弹暴击率（精准打击 / 战斗直觉） | **无效** —— DOT 有自己的暴击率 |
| 子弹暴击伤害（致命一击 / 精通） | **无效** —— DOT 有自己的暴击伤害 |
| 子弹攻速（攻速强化 / 弹幕流射速） | **无效** —— DOT 有自己的跳数间隔 |
| 弹道数量（弹幕流全部） | **无效** |
| 命中积累（每命中 +0.0025 伤害） | **无效** —— DOT 跳数不产生命中积累 |
| 弱点打击 / 背水一战 | **无效** |

反过来，**想把 DOT 做强，只能拿辐射流自己的增益**。这是设计上的取舍：
DOT 流不开火也能输出，所以不能同时吃到子弹流的全部乘区。

> 实现上，DOT 直接扣 `hp`，不经过 `damageMultiplier()` / `hitBonus()` /
> `execute` / `berserk`，也不调用 `addHit()`。它的数值出口只有这几个字段：
> `S.dotPerStack / dotPerHit / dotMax / dotInterval / dotDuration / dotCritChance / dotCritMul`。

### ⚙️ 通用（31 个）

**子弹类型（本体造型 4 种 + 元素光晕 4 种）**

> **造型与元素是分开的两层**：`style` 决定弹体（普通 / 激光 / 重型 / 轨道），

### 💥 击破奖励 —— 后期靠它跟上难度

**问题**：敌机血量是**乘法增长**的（`×1.2^关卡` 再叠每十关 ×2.2 的台阶），
而玩家的强化是**加法**的、而且很快会点满。两条曲线必然发散 ——
实测到第 20 关 Boss 就要打 **2 分 17 秒**，再往后基本打不动。

**解法**：给玩家也加一条乘法曲线。

```
击破奖励 = 2 ^ 已击破 Boss 数        每击破一位 Boss，伤害 ×2（永久，可无限叠加）
```

它是一条**独立的「关卡进度」乘区**，同时作用于**子弹**与**持续伤害**两条通道。
左上角战斗面板会显示当前倍率，击破时也会弹提示。

> 它**不是子弹增益**，所以不违反"辐射流不吃子弹加成"那条规则 —— DOT 一样吃得到。

**实测效果**（不死玩家 + 智能选强化，同样跑 12 分钟）：

| | 加之前 | 加之后 |
|---|---|---|
| 第 10 关 Boss 耗时 | 99.3 秒 | **53.1 秒** |
| 第 20 关 Boss 耗时 | 136.7 秒 | **43.4 秒** |
| 12 分钟能推到 | 第 20 关 | **第 27 关** |
| 普通关耗时 | 25 秒 | 22~28 秒（不变） |

### ⏱️ 超时过载 —— 保证不会卡死

Boss 战打满 **10 分钟**仍未结束，Boss 会进入 **核心过载**：
整体泛红脉冲，并且**每秒损失 2% 最大生命**。

这是兜底机制 —— 不管构筑多离谱（或者你故意不带输出），
一场 Boss 战都会在约 11 分钟内收束，不会出现永远打不完的僵局。
血条下方会显示过载倒计时（最后 60 秒开始提示）。

### 难度曲线

设计目标：**前 10 关友好，之后每 10 关整体指数跳一个台阶。**

**小怪血量** = `连续成长曲线 × 台阶倍率`

| 项目   | 第 1~10 关           | 第 11 关起                   |
| ---- | ------------------ | ------------------------- |
| 连续成长 | `1 + (关−1)×0.16`   | `2.44 × 1.16^(关−10)`      |
| 每关数量 | `min(6 + 关×2, 22)` | `26 × 1.12^(关−10)`（上限 60） |
| 刷新间隔 | 0.75s → 0.48s      | 0.46s → 最快 0.14s          |
| 精英怪  | **不出现**            | 6% → 26%                  |

**台阶倍率**（每 10 关翻一次）：第 1~10 关 ×1 → 第 11~20 关 **×2.2** → 第 21~30 关 **×4.84** → 第 31~40 关 **×10.65**

实测数值：

| 关卡         | 小怪血量倍率         | Boss 血量    |
| ---------- | -------------- | ---------- |
| 第 10 关     | ×2.44          | 760（钢铁蜂巢）        |
| **第 11 关** | **×6.23**（跳台阶） | 2,006      |
| 第 20 关     | ×23.68         | **11,905**（虚空掠夺者 ×1.15） |
| **第 21 关** | **×60.43**（再跳） | 31,430     |
| 第 30 关     | ×229.82        | **183,327**（熔核巨舰 ×1.30） |
| 第 40 关     | ×2230          | **2,785,396**（深空仲裁者 ×1.45） |
| 第 50 关     | ×21,600        | 41,867,222（终焉之影 ×1.60） |
| 第 60 关     | ×209,000       | 641,596,231（噬星者 ×1.80） |

Boss 血量 = `(160 + 关卡×60 ≤10关 / 760×1.20^(关−10) >10关) × 台阶倍率 × 该 Boss 的血量倍率`

**所有敌机的移动速度整体下调了约 25%**，靠数量与血量制造压力，而不是靠"糊脸冲刺"。

## 怎么发给别人玩

不需要服务器，也不需要对方装任何东西。

### 方式 A：发一个 HTML 文件（推荐）✅

```bash
node tools/build.js
```

会把整个游戏压成一个 **`dist/星际突袭.html`（约 213 KB）**，CSS 和 13 个 JS 模块全部内联，
**零外部引用**。把这个文件直接发给对方（微信 / QQ / 邮件 / 网盘都行），**双击就能玩**。

> 单文件版已经用完整的 **498 项测试**验证过可以正常运行，不是"看起来对"。

### 方式 B：发源码压缩包

`dist/flying-shooter-source.zip`（约 70 KB）包含 `index.html` + `css/` + `js/` + `README.md`。
对方解压后双击 `index.html` 即可 —— **不需要 `npm install`，不需要起服务器**。

### 方式 C：直接给网址（手机用户最方便）

**线上站点：<https://elaborate-mandazi-62d152.netlify.app/>**

已通过 **Netlify** 托管，并连接了本 GitHub 仓库 —— 每次 `push` 到 `main` 都会自动重新部署，不需要手动上传。
根目录的 `netlify.toml` 已声明「纯静态、无需构建」，Netlify 会自动读取。

### 方式 D：同一个局域网直接分享

```bash
npx serve .          # 或 python -m http.server 8080
```

让对方访问 `http://你的内网IP:端口`（`ipconfig` 查 IPv4 地址）。

### 模块约定

所有模块统一挂到 `window.Game` 上，`main.js` 调用前一律做**存在性检查**：

```js
if (Game.enemies && Game.enemies.update) Game.enemies.update(dt);
```

配合 `Game.stats` 属性表与 `Game.heal()` 这类公共接口，使得：

- 每个模块都可以**单独运行、单独测试**
- 删掉任意一个模块，游戏依然能跑（只是少了那部分功能）

**数据流**：`progress.js`（等级）→ `upgrades.js`（聚合出 `Game.stats`）→ `player / bullets / combat / enemies` 只读属性表。

## 技术要点

- **固定逻辑尺寸 + 高 DPI**：按 `devicePixelRatio` 缩放画布，逻辑坐标始终不变
- **增量时间**：`dt` 钳制在 50ms 以内，切标签页回来不会"瞬移穿模"
- **属性表模式**：所有增益只改数据，不改行为分支
- **满级自动出池**：抽取时先过滤满级增益，权重再加一道 0 保险，避免"满级还占抽卡位"
- **弹道可见性下限**：缩小类增益叠加时，判定半径与线宽都有下限，不会出现"看不见的子弹"
- **波动弹相位**：相位由「世界时间 + 出场横坐标」共同决定，所以同一轮里是连续的蛇形波，不同轮次也不会重合成同一波形（早期版本用子弹自身寿命做相位，叠射速后所有波形会同步）
- **伤害聚合**：飘字按敌机汇总、0.34 秒弹一次，弹幕流下也不会糊屏
- **绘制降级**：同屏子弹超过 140 发时自动省掉外层光晕与长拖尾，保住帧率
- **音效节流 / 音频降级**：同名音效有时间窗；没有 WebAudio 时全部安全静默
- **UI 分区**：底部留给等级与经验条，左上留给战斗面板，Boss 血条独占顶部一条
- **演出保护**：Boss 击破动画播放期间会推迟强化弹窗，避免把爆炸冻在半路

## 开发自测

`tools/smoke-test.js` 是一个**无浏览器测试台**：用极简的 DOM / Canvas / WebAudio 桩，
把游戏脚本放进 Node 的 `vm` 里真实驱动游戏循环，逐项验证核心逻辑。

```bash
node tools/smoke-test.js
```

另外有一个**数值探针**，用来量化 DOT 的实战贡献并复查"不串味"：

```bash
node tools/dot-probe.js
```

它会跑 4 组对照：纯子弹流 / 子弹流+满辐射流 / 同等级辐射流在子弹加成前后的 7 项数值对比 /
只拿子弹流时的 DOT 伤害必须为 0，最后还会验证"高频衰变 / 衰变链"确实提高了 DPS。

覆盖 **498 项断言**：

- 框架 / 操作 / 战斗基础（状态机、自动开火、边界、受击、过关）
- 增益：**113 个增益逐项属性映射**、层数叠加、三选一流程
- **满级归零**：满级增益 3000 次抽取零出现、不影响其它增益、全满级抽不出任何选项
- **金色品质**：通用流派没有金色、门槛前抽不到、达标后解锁、概率极低、等级越高概率越高
- **流派倾向**：未投入时权重相等、主玩流派权重升高、其它降低、通用不变；统计验证出现频率差异；
  **权重表不含 NaN**（新增流派若漏登记会直接 NaN，这条守住）
- **舰队流**：僚机数量与 20 架上限、召唤物数组同步、**25% 继承公式**、继承比例可升级、
  继承本体弹道数量并设单机上限、**本体堆弹道后僚机弹道确实增加（回归 floor 吞小数）**、
  火力共享/快速循环/协同瞄准/精英护航各自生效、
  **神经链接让僚机反哺本体伤害**、实战中僚机真的开火并命中、编队横向展开且不出屏、
  金色舰队增益解锁与效果
- **辐射流（独立 DOT 通道）**：
  - 三源合流：燃烧 / 剧毒 / 辐射共用**同一份层数**（目标身上只有一个 `dotStacks`）
  - **不点火就没有伤害**：只拿燃烧弹 / 剧毒弹不会自己产生伤害
  - **独立性回归测试**（本流派的核心约束）：把子弹伤害 / 暴击率 / 暴击伤害 / 攻速 /
    弹道数量 / 命中积累 / 弱点打击 / 背水一战全部堆满，断言 DOT 的
    `每层伤害 / 层数上限 / 跳数间隔 / 暴击率 / 暴击伤害` **一个都没变**
  - **DOT 跳数不喂"命中积累"**（跑 120 帧跳数，`state.hits` 必须仍为 0）
  - DOT 自己的强化手段有效：衰变强化 / 致命衰变 / 毁伤衰变 / 双重衰变 / 临界引爆
  - **回归：缩短跳数间隔必须真的提高 DPS**（曾经 `DPS = 跳伤 ÷ 间隔` 把间隔约掉，
    导致"高频衰变""衰变链"完全无效）、跳数间隔有 0.05s 硬下限
  - 临界引爆后层数减半（不会自我回叠层数）、引爆伤害随 DOT 强度缩放
  - 层数 = 命中次数 × 每次层数、层数越高每跳伤害越高、持续时间到自动清零
  - **Boss 也吃 DOT**、金色门槛解锁、面板按需显示、满层渲染不崩
- **子弹外观分层**：本体造型 4 种互相区分、元素只加光晕不改本体（回归"子弹突然变紫变粗"）、
  多种元素可以同时叠在同一个弹体上
- **Boss 花名册（6 位）**：
  - 第 10/20/30/40/50/60 关各对应一位、第 70 关轮回并标记「第 N 形态」
  - 名字 / 代号 / 内部 id / 配色 **两两互不重复**
  - 血量倍率、弹速、开火频率都随顺位**单调递增**
  - **外形指纹测试**：把每个 Boss 的绘制调用录下来（操作名 + 取整坐标），
    断言 6 份指纹两两不同、指令数 > 40（不是空函数）、任意两种重合度 < 90%
  - 每位 Boss 都能入场、持续开火、跑 400 帧不崩、被击破、掉落补给、给分
  - 隐形的终焉之影**不会撞死玩家**，显形后依然会撞
  - 血条 UI 在三个阶段都能绘制
- **追踪弹头削弱**：转向率远低于旧版、收益递减、飞完一屏转不到 130°、
  身后的目标不追（锥形）、锁定后不换目标、弹速确实变慢
- **击破奖励**：每击破一个 Boss 伤害 ×2、可叠加、同时提升子弹与 DOT、
  开新一局会清零、真实击破会自动加层、面板会显示
- **超时过载**：阈值 = 600 秒、每秒掉 2% 最大生命、掉血速率实测吻合、
  能把血量 1e15 的 Boss 收掉、没到时间不会掉血
- **舰队流命中积累**：僚机吃到加成、且**严格等于本体的 25%**、
  僚机子弹带 `bonus` 字段而本体子弹不带
- **面板自适应**：6 种窗口高度（1000→360）下面板都不压底部经验条、
  都不盖住玩家默认站位；小窗口会自动截断且仍显示 ≥ 4 行；恢复尺寸后回到完整
- **跨局存档**：局数 / 击杀 / 击破数 / 最高关卡都会累加，低关卡不覆盖记录，
  损坏的 JSON 安全降级，生命值显示封顶不崩
- **图鉴**：三个标签页都能生成内容、增益页列出全部 113 个、
  Boss 页列出全部 6 位、能打开/切页/关闭
- **卡面文案**：每个增益都有 `delta`、卡面真的渲染出「升级 +1 级」
- **难度曲线**：台阶倍率在第 10/20/30 关不变、第 11/21/31 关各跨一档、台阶内成长平缓、
  小怪与 Boss 血量都按十关跳台阶且整体单调递增、精英怪 11 关解锁、怪速下调、掉落率下调
- **子弹可见性**：最小半径下限、极端缩小后仍可见、7 种风格都能正常绘制
- **子弹类型**：激光/聚能/波动/弹跳/追踪/等离子/霜冻/电弧/剧毒/轨道各自生效
- **波动弹相位**：初始相位公式、同轮各弹道相位不同、跨轮次相位不同
- **点防范围指示环**：指示环半径 = 实际清除半径、从中心扩散、自动回收不泄漏粒子
- **等离子溅射节流**：40 次高射速命中，同屏 ring 粒子峰值 ≤ 3
- **战斗面板**：暴击率/暴击伤害（百分比）/攻速/弹道/秒伤/僚机/持续伤害、数值随增益变化、**不遮挡底部经验条与 Boss 血条**
- **伤害显示**：命中飘出纯数字、秒伤统计有值、DOT 飘字单独标类型
- **命中积累**：无上限持续增长、单次加成大幅调低
- **暴击上限**：堆到 448% 也会被压回 100%
- 经验系统 / 特殊效果 / 道具流 / Boss 全流程 / 音效
- 稳定性：连续 5400 帧（模拟左右横扫的玩家 + 自动选增益 + 主动送死重开）无异常
