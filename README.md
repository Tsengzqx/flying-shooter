## 核心循环

```
自动开火 → 击毁敌机 → 获得经验 → 经验条满 → 等级 +1 → 【三选一强化】 → 变更强 → 打更难的关
```

**强化不靠过关，靠升级。** 越主动清怪、越能滚起雪球。
屏幕底部是经验条（左侧等级，右侧 `当前经验 / 升级所需`）。

## 增益系统（83 个）

### 四档品质

| 品质     | 颜色    | 说明                    |
| ------ | ----- | --------------------- |
| 普通     | 蓝     | 基础强化                  |
| 稀有     | 青     | 有明确取舍或机制              |
| 史诗     | 紫     | 强力机制，每个流派都有 4~6 个     |
| **金色** | **金** | **流派的终极增益，需要解锁，概率极低** |

### 金色增益的解锁规则

- 某个流派累计获得 **8 层增益** 后，该流派的金色增益才会进入抽取池
- 基础权重只有 **0.8**（普通是 62），所以出现概率**极低**
- 权重随**玩家等级**提升：`0.8 × (1 + 等级 × 0.12)`，等级越高越容易见到
- 金色增益只有 1 级，拿到就是质变
- 通用流派没有金色增益（金色只属于三大流派）

### 满级增益的出现概率为 0

任何增益拿到最高级（例如「弹跳弹」2 层）后，**会被彻底移出抽取池**，出现概率严格为 0
（过滤 + 权重双重保险，有 3000 次抽取的测试守着）。全部增益都满级时，升级不会再弹出强化面板。

### 流派倾向（越玩越专精）

系统会统计你在每个流派上投入的层数，然后调整出现概率：

| 情况       | 权重              |
| -------- | --------------- |
| 主导流派     | 最高约 **×2.1**    |
| 冷门流派     | 最低约 **×0.5**    |
| **通用增益** | **恒为 ×1（不受影响）** |

也就是「你玩什么流派，就更容易抽到什么流派的增益」，同时保留转型的可能。

### 卡面会告诉你「升级多拿到什么」

每张强化卡都写了两行：**当前效果** + **升级 +1 级额外获得什么**，例如：

```
〰️ 波动弹                       [通用]
子弹左右摆动前进，横向覆盖更宽
升级 +1 级：摆动幅度 +60%，波频更高
Lv 1 → 2
```

## 敌人与 Boss

### 7 种机型 + 精英变异

| 敌机      | 特点                  | 出现      | 经验  |
| ------- | ------------------- | ------- | --- |
| 🔺 侦察机  | 直线俯冲，血少分低，偶尔点射      | 第 1 关起  | 2   |
| 🔷 游走机  | 左右蛇形走位，会瞄准射击        | 第 3 关起  | 4   |
| 🛑 炮艇   | 移动慢、血厚，三向扇形弹幕       | 第 4 关起  | 9   |
| 🔻 冲角机  | 悬停蓄力后**锁定玩家高速俯冲**   | 第 5 关起  | 6   |
| 🕸️ 织网者 | 横移布网，把一整排弹幕推过来      | 第 6 关起  | 7   |
| 🟢 分裂体  | 环形弹幕；**击毁后裂成两只侦察机** | 第 8 关起  | 8   |
| 👑 护卫舰  | **准 Boss**：血厚、双段弹幕  | 第 12 关起 | 22  |

**★ 精英怪**：**第 11 关起**才出现。金色光环 + ★ 标记，体型更大、
**血量 ×3.5、分数 ×4、经验 ×3**，多打一轮弹幕，**必掉一个道具**。
出现率随关卡上升（第 11 关 6% → 第 22 关 26%）。

难度梯度：**普通小怪 → 精英怪 → 护卫舰 → Boss**。

### 难度曲线

设计目标：**前 10 关友好，之后每 10 关整体指数跳一个台阶。**

**小怪血量** = `连续成长曲线 × 台阶倍率`

| 项目   | 第 1~10 关           | 第 11 关起                   |
| ---- | ------------------ | ------------------------- |
| 连续成长 | `1 + (关−1)×0.16`   | `2.44 × 1.16^(关−10)`      |
| 每关数量 | `min(6 + 关×2, 22)` | `26 × 1.12^(关−10)`（上限 60） |
| 刷新间隔 | 0.75s → 0.48s      | 0.46s → 最快 0.14s          |
| 精英怪  | **不出现**            | 6% → 26%                  |

**台阶倍率**（每 10 关翻一次）：第 1~10 关 ×1 → 第 11~20 关 **×2.2** → 第 21~30 关 **×4.84** → 第 31~40 关 **×10.65**

实测数值：

| 关卡         | 小怪血量倍率         | Boss 血量    |
| ---------- | -------------- | ---------- |
| 第 1 关      | ×1.00          | 220        |
| 第 5 关      | ×1.64          | 460        |
| 第 10 关     | ×2.44          | 760        |
| **第 11 关** | **×6.23**（跳台阶） | **2,006**  |
| 第 15 关     | ×11.27         | 4,160      |
| 第 20 关     | ×23.68         | 10,353     |
| **第 21 关** | **×60.43**（再跳） | **27,331** |
| 第 30 关     | ×229.82        | 141,021    |
| 第 40 关     | ×2230          | 1,920,963  |

Boss 血量 = `(160 + 关卡×60 ≤10关 / 760×1.20^(关−10) >10关) × 台阶倍率`

**所有敌机的移动速度整体下调了约 25%**，靠数量与血量制造压力，而不是靠"糊脸冲刺"。

### Boss 战（每 5 关）

- **Boss 关也会持续刷小怪**：Boss 登场 3 秒后开始出护卫兵，间隔 1.3~2.2 秒
- 按剩余血量分三阶段：瞄准扇形+环形 → 追加弹雨 → 螺旋弹幕 + 召唤小怪
- 击破后掉落补给并给大量经验

## 怎么发给别人玩

不需要服务器，也不需要对方装任何东西。

### 方式 A：发一个 HTML 文件（推荐）✅

```bash
node tools/build.js
```

会把整个游戏压成一个 **`dist/星际突袭.html`（约 186 KB）**，CSS 和 13 个 JS 模块全部内联，
**零外部引用**。把这个文件直接发给对方（微信 / QQ / 邮件 / 网盘都行），**双击就能玩**。

> 单文件版已经用完整的 **313 项测试**验证过可以正常运行，不是"看起来对"。

### 方式 B：发源码压缩包

`dist/flying-shooter-source.zip`（约 70 KB）包含 `index.html` + `css/` + `js/` + `README.md`。
对方解压后双击 `index.html` 即可 —— **不需要 `npm install`，不需要起服务器**。

### 方式 C：直接给网址（手机用户最方便）

**线上站点：<https://elaborate-mandazi-62d152.netlify.app/>**

已通过 **Netlify** 托管，并连接了本 GitHub 仓库 —— 每次 `push` 到 `main` 都会自动重新部署，不需要手动上传。
根目录的 `netlify.toml` 已声明「纯静态、无需构建」，Netlify 会自动读取。

### 方式 D：同一个局域网直接分享

```bash
npx serve .          # 或 python -m http.server 8080
```

让对方访问 `http://你的内网IP:端口`（`ipconfig` 查 IPv4 地址）。

### 模块约定

所有模块统一挂到 `window.Game` 上，`main.js` 调用前一律做**存在性检查**：

```js
if (Game.enemies && Game.enemies.update) Game.enemies.update(dt);
```

配合 `Game.stats` 属性表与 `Game.heal()` 这类公共接口，使得：

- 每个模块都可以**单独运行、单独测试**
- 删掉任意一个模块，游戏依然能跑（只是少了那部分功能）

**数据流**：`progress.js`（等级）→ `upgrades.js`（聚合出 `Game.stats`）→ `player / bullets / combat / enemies` 只读属性表。

## 技术要点

- **固定逻辑尺寸 + 高 DPI**：按 `devicePixelRatio` 缩放画布，逻辑坐标始终不变
- **增量时间**：`dt` 钳制在 50ms 以内，切标签页回来不会"瞬移穿模"
- **属性表模式**：所有增益只改数据，不改行为分支
- **满级自动出池**：抽取时先过滤满级增益，权重再加一道 0 保险，避免"满级还占抽卡位"
- **弹道可见性下限**：缩小类增益叠加时，判定半径与线宽都有下限，不会出现"看不见的子弹"
- **波动弹相位**：相位由「世界时间 + 出场横坐标」共同决定，所以同一轮里是连续的蛇形波，不同轮次也不会重合成同一波形（早期版本用子弹自身寿命做相位，叠射速后所有波形会同步）
- **伤害聚合**：飘字按敌机汇总、0.34 秒弹一次，弹幕流下也不会糊屏
- **绘制降级**：同屏子弹超过 140 发时自动省掉外层光晕与长拖尾，保住帧率
- **音效节流 / 音频降级**：同名音效有时间窗；没有 WebAudio 时全部安全静默
- **UI 分区**：底部留给等级与经验条，左上留给战斗面板，Boss 血条独占顶部一条
- **演出保护**：Boss 击破动画播放期间会推迟强化弹窗，避免把爆炸冻在半路
